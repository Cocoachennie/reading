# Leaf · 外刊阅读室

面向考研英语、IELTS、TOEFL 的第一版阅读网站。Python 3.12+ 标准库后端 + 原生 HTML/CSS/JavaScript，无第三方运行依赖或注册流程。

## 运行

```bash
cd /workspace/reading
python server.py
```

默认监听 8000，可通过 `PORT=8080 python server.py` 改端口。主页由同一进程提供，API 无跨域依赖。默认公开模式：共享 RSS 元数据缓存写入忽略的 `.local/public-feeds.json`，手动导入文章、正文、收藏及原文打开记录仅保存在访客各自浏览器。全文在浏览器本地分析，不发送给服务器；备份导入导出不含全文。服务端不接受访客文章写入，每个实例的来源更新尝试间隔至少 60 秒。兼容原始本地服务端导入模式可显式设 `PUBLIC_MODE=0`，此模式仅适合可信单用户环境，不应公开部署。

## 已实现

- 三个考试入口，独立编辑主题分类；按主题、来源、发布日期、估计难度、篇幅及标题搜索筛选。
- 响应式卡片、中文简介、来源/日期、标签、推荐理由、原文链接、收藏、打开原文记录。
- 在浏览器本地手动导入链接和元数据；正文需用户确认合法取得且为完整正文。不会访问任意导入 URL，也不会抓取正文或绕过付费墙。
- Guardian Science / Environment、NASA News RSS 后端获取器。仅存储公开标题、链接、发布日期；不保留 RSS 摘要或正文。自动中文翻译未启用，真实 RSS 条目显示明确的简介缺失提示。
- 更新按钮、逐源真实成功/失败状态、最近尝试时间、上次成功时间。失败不清空文章或上次成功时间；以原文 URL 去重。
- 首次运行有 6 条明确标注的虚构演示数据，均不是来源实际发布的文章，无原文链接或伪造日期。
- 本地文章导入、收藏、打开原文记录、JSON 导出与合并导入、格式验证、安全文本渲染和 HTTP(S) 链接验证。

## 分析边界

主题初筛用编辑维护的词组库和多个独立线索，要求线索在 60 词局部窗口共同出现，最低阈值为 2，可调高；考研、IELTS、TOEFL 分类各自独立。它是可解释的初筛，尚不是语义模型或人工审核结论；未获取正文时明确以元数据初筛展示，不当作全文适配分析。未分类条目仍展示为待复核。

获授权完整正文可统计英文词数、平均句长、≥8 字母词比例；至少 80 词且 3 句才估计难度。句长和长词比例是粗略代理，不是 CEFR、考试官方等级、真正的词汇频率或句法分析。句长/篇幅/主题阈值可调整，长词阈值公开为 17% 和 27%。英文词的内部撇号和连字符视作同一个词。

未取得全文时，词数及难度显示“暂无法分析”。考研高频词覆盖率始终不可用：尚无合法真实真题语料，没有年份范围、词频表或统计分母。尚无已核实真题来源，任何文章都不标为“真题来源”。未来需要授权语料、明确年份/卷种、词形处理、停用词及频次阈值定义，以及可核查的来源采用证据，才能实现这些指标。

IELTS/TOEFL 目前只实现独立主题初筛，专用全文阅读适配评分未实现。词汇学习、阅读题目与训练、语义模型、人工审核队列和自动翻译留待后续扩展。

## Render 一键部署（无需终端）

仓库已包含 `render.yaml`，创建 Python Web Service，指定 Free 计划、公开模式、健康检查 `/healthz` 与启动命令。没有第三方依赖、数据库或付费磁盘。

1. 打开 [Render 部署入口](https://dashboard.render.com/blueprint/new?repo=https%3A%2F%2Fgithub.com%2FCocoachennie%2Freading)。登录或注册 Render，可使用 GitHub 账号。
2. 若提示授权 GitHub，连接 `Cocoachennie/reading` 仓库。在 Blueprint 页面为部署命名（例如 `reading`），确认 Web Service 的计划为 **Free**，然后提交部署（按钮可能显示 Deploy Blueprint / Apply）。
3. 等待服务显示 **Live**，打开 Render 服务页面提供的 `https://…onrender.com` 网址。首次唤醒可能较慢。点击更新来源，检查每个来源的真实获取状态；当前 Codex 环境已成功获取三个 RSS，但这不代表 Render 上自动获得相同结果，仍需实测。

若 Blueprint 页面无法自动识别仓库，也可在 Render 点击 **New → Web Service → Git Provider**，选择 `Cocoachennie/reading`，分支 `main`，语言 Python，Build Command 为 `python -m unittest discover -s tests -v`，Start Command 为 `python server.py`，计划 Free，环境变量 `PUBLIC_MODE=1` 和 `PYTHON_VERSION=3.12.14`，健康检查路径 `/healthz`。

免费服务的共享 RSS 缓存不持久化，休眠重启或重新部署可能丢失服务器缓存和上次更新时间，需要再次点击更新；浏览器个人数据仍在各访客浏览器中。清除浏览器数据或更换网站域名会使原有个人数据不可见，请定期导出备份；备份不包含正文，合法原始正文文件需另行保管。定时更新尚未启用。

Render 账号登录、GitHub 授权和平台创建服务需要仓库所有者在平台完成。提交部署配置到 GitHub 并不代表已经创建公网服务；只有拿到实际网址并完成外部检查后，才能确认上线成功。
